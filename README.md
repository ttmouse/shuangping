
# 双拼在线练习软件

一个现代化的双拼输入法在线练习工具，专为快速入门双拼打字而生，提供声母、韵母专项练习功能。

## ✨ 主要特性

### 🎯 多模式练习
- **声母韵母练习**：专项训练声母和韵母的键位记忆
- **文章打字练习**：支持内置文案和自定义文本导入
- **随机练习**：根据字数范围智能生成练习内容

### ⌨️ 多方案支持
支持8种主流双拼方案：
- 小鹤双拼
- 微软双拼
- 搜狗双拼
- 自然码
- 紫光双拼
- 加加双拼
- 国标双拼
- ABC双拼

### 🎵 语音功能
- 自动朗读韵母发音（可选开关）
- 点击重复朗读功能
- 基于真人录音的音频文件

### 🎨 现代化界面
- **Figma风格深色主题**：美观专业的深色界面
- **响应式设计**：完美适配桌面和移动设备
- **实时视觉反馈**：按键高亮、卡片动画效果
- **流畅动画**：完成卡片的倒下动画效果

### ⚙️ 丰富设置
- 拼音/双拼编码显示切换
- 键盘显示/隐藏
- 音效开关和音量调节
- 自动朗读开关
- 自定义文案管理

## 🚀 快速开始

### 在线使用
直接访问项目主页开始练习，无需安装。

### 本地开发

```bash
# 克隆项目
git clone [项目地址]
cd shuangping

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 📖 使用指南

### 1. 选择双拼方案
在练习页面的操作区域点击"双拼方案"下拉菜单，选择你熟悉的方案。

### 2. 声母韵母练习
- 选择练习范围（第一排/第二排/第三排/全部按键）
- 点击"开始"或按任意键盘按键开始练习
- 根据显示的韵母输入对应的双拼编码
- 可以开启"自动朗读"功能辅助学习

### 3. 文章打字练习
- 选择内置文案或导入自定义中文文本
- 系统会自动转换为单字练习模式
- 支持实时显示拼音和双拼编码
- 完成后可查看练习统计

### 4. 自定义文案
- 点击"导入文本"按钮
- 粘贴中文文本（最多1000字）
- 系统自动提取并生成练习内容

## 🎯 练习技巧

1. **从韵母开始**：先掌握韵母的键位分布，这是双拼的核心
2. **循序渐进**：建议按第一排→第二排→第三排的顺序练习
3. **重复练习**：利用自动朗读功能，形成肌肉记忆
4. **速度优先**：初期不要过于追求准确率，先建立键位直觉
5. **多样化内容**：结合不同类型的文案练习，提高适应性

## 🛠️ 技术栈

- **Vue 3** + **Composition API** - 现代化前端框架
- **Pinia** - 状态管理
- **Vue Router** - 路由管理
- **Vite** - 构建工具
- **原生Web Audio API** - 音频播放
