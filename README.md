# 双拼练习工具

一个基于 Vue 3 的双拼输入法在线练习工具，帮助用户快速掌握双拼输入技巧。

## 功能特性

- 多种双拼方案支持（小鹤、自然、搜狗、微软等）
- 声母和韵母专项练习
- 自定义文本导入练习
- 实时音频反馈
- 键盘隐藏功能
- 响应式设计，支持移动端
- 主题系统（亮色/暗色）
- 性能监控工具

## 在线体验

访问 https://your-domain.com 立即体验

## 本地开发

### 环境要求

- Node.js 16+
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 开发命令

```bash
npm run dev     # 启动开发服务器
npm run build   # 构建生产版本
npm run preview # 预览构建后的应用
```

## 双拼方案

项目支持以下双拼方案：

1. 小鹤双拼
2. 自然双拼
3. 搜狗双拼
4. 微软双拼
5. ABC双拼
6. 佳佳双拼
7. 紫光双拼
8. 国际双拼
