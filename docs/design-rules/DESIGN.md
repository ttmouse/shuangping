# shuangping 双拼练习设计规范

> 权威正本。项目内文档引用规则一律带 § 编号指向这里，不复制内容。
> 修改视觉规则须经设计确认；具体数值变更记入 design-decision-log.md。
> 规则分两层：**【基础】**继承自 shared/design-foundation/，全项目默认生效；**【项目】**本项目专属拍板，差异点见决策日志。

## §1 视觉语言与定位

【基础】工具类产品：界面服务于任务，内容优先，装饰克制；颜色只用于表达语义，不做纯装饰。
【项目】双拼/英语练习工具，目标是让用户长时间练习不疲劳。气质是"清爽 + 鼓励感"：浅绿主色传达平和学习氛围，练习反馈（对/错/选中）是全界面唯一允许感官刺激的地方——键盘闪烁、抖动、发光都集中在这里，其余界面保持安静。忌讳：大面积高饱和色、密集卡片堆叠。

## §2 颜色

【基础】亮暗两版都要定义；语义色分：背景/主文字/次要文字/主色/成功/错误/警示/边框，各司其职不复用。
【项目】当前值以 CSS 变量为契约（src/assets/styles.css）：

| 角色 | 亮 | 暗 |
|---|---|---|
| 页面背景 | `#ffffff` | `#0f172a` |
| 浮层/卡片底 | `#ffffff` | `#1e293b` |
| 主文字 | `#1f2937` | `#cbd5e1` |
| 次要文字 | `#6b7280` | `#64748b` |
| 主色（品牌绿） | `#1a9a7a` | `#2ec4a0` |
| 主色悬停 | `#2ec4a0` | `#3ddbbc` |
| 强调（星级/目标） | `#b8860b` | 沿用亮色值 |
| 成功 | `#2e9e5b` | `#34d399` |
| 错误 | `#d9534f` | `#f87171` |
| 警示 | `#e6a23c` | `#fbbf24` |
| 边框（hairline） | `#e2e5ea` | `#334155` |
| 键位反馈-成功闪光 | `--theme-flash-ok`（亮暗同值） | |
| 键位反馈-错误闪光 | `--theme-flash-bad`（亮暗同值） | |

规则：
- 实现一律用 `var(--theme-*)`，不写裸 hex；透明度衍生色用 `color-mix` 派生（2026-09-30 裁决：flash 色已收进变量，唯一剩余 hex 豁免为 §4 qtip 气泡深底）。
- 反馈绿 `#52c41a` / 红 `#ff4d4f` 与语义色成功/错误并存：前者只用于键盘瞬时闪光的强反馈，后者用于常规错误态。

## §3 排版

【基础】系统字体栈即可，不引外部字体；正文与界面文字区分层级，标题用色不用大加粗堆叠。
【项目】字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- 页面主标题 h1：22px / 主色调
- 副标题 h2：14px / 次要色 / 不加粗
- 键帽大字母：28px / 700（可辨识优先）
- 键帽辅助注音：16px；mzn 辅助注解 12px / 600
- 正文/提示：14–16px，行高 ≥1.5
- 最小字号 12px（气泡、脚注）

## §4 组件

【基础】按钮/输入/卡片逐态完整（默认/悬停/按下/禁用），交互态用色和边框表达，不引入意外投影。
【项目】核心组件是可按压的键位方块（keyBox）：
- 底态：卡片底色 + 1px 边框 + 圆角 8px + 极轻投影 `0 2px 0 rgba(0,0,0,0.03)`
- 悬停：边框变主色悬停色
- 按下：`translateY(1px)` 下沉
- 选中：主色边框 + 内外主色微光
- 对答闪光：绿色边框 + 内外绿光 + pop 动画（scale 1→1.035，0.22s）
- 错答闪光：红色边框 + 红色内阴影/外光 + 全屏红色蒙层 8% + shake 动画（0.18s，±2px）
- 弹窗 modal：720px / max-width 92vw / 圆角 10px / 1px 边框 / `0 6px 16px rgba(0,0,0,0.18)` 投影
- 悬停气泡 qtip：深底白字（`rgba(22,22,28,0.92)`）圆角 6px，hover 立即出现（0.08s），最高层级，不受容器裁剪

## §5 布局

【基础】间距成阶梯（4 的倍数档），对齐优先于填充。
【项目】密度档当前值：4 / 8 / 10 / 12 / 14 / 20 / 30 / 36 / 40 px。圆角档位：6（气泡）/ 8（键位、容件）/ 10（modal）。
- 键盘宽 1040px、max-width 96%，居中
- 页面内容 max-width 700px 者居中留白，不拉满
- 全屏遮罩（modalMask）z-index ≥ 界面最高层（现约定 1001，界面元素顶格 1000），新增浮层沿用此约定

## §6 交互约定与动效

【基础】动效只在可用性上有意义时存在；时长层级：状态反馈 < 布局变化 < 页面进入。
【项目】动效 token：瞬时闪 0.05s(按下沉) / 0.08s(气泡) / 0.15s(边框过渡) / 0.18s(错误 shake) / 0.22s(成功 pop)。缓动一律 ease。
- 练习反馈失败要有"整屏轻微警示"（红色蒙层），成功只亮键位本身——错误感重、成功感轻，符合纠错练习的心智
- 键盘方向键导航焦点可见：2px outline 主色悬停色 + offset 2px，不可去掉
- 音效与视觉反馈成对出现，不出现"只见闪不动听"的实现

## §7 内容规范

【基础】中文为主；错误提示说"怎么改"，不说技术术语。
【项目】鼓励文案真实具体，不用浮夸感叹号连环；练习计数、进度、星级数字用等宽呈现避免跳动。

## §8 平台补充

【项目】Web 应用，需兼容键盘全键盘操作（练习页方向键导航已是硬要求）；暗色为正式主题之一，新增颜色必须同时给出暗色值，缺暗色的实现视为未完成。

## §9 决策留痕
