英文练习 · 记忆强化升级蓝图

从「单次会话内的集中重复」升级为「内层刻意练习 × 外层间隔重复（SRS）」的双闭环——让练错、练慢的词在遗忘边缘被主动召回，间隔逐步拉长，进入长期记忆。

结构示意 · 非算法精确曲线 · 参考 Anki(SM-2) / FSRS / 刻意练习

① 核心诊断：现在只有「会话内记忆」，缺「跨天记忆模型」

左：现有强化全部集中在一次练习内，且被最近一次表现覆盖；右：新增跨天间隔闭环，在遗忘边缘复习。

现状 单会话 · 集中闭环

错词加权 / 慢词连打 N 遍 / 当场重入队 —— 短期流利，长期保持差

↺ 仅在「本次会话 / 本课」内循环，关掉页面即失忆
缺口：没有到期日 / 间隔 / 遗忘曲线；没有跨课包的「今日复习」；周一会的词周五照样忘。

目标 双闭环 · 长期记忆

内层刻意练习（会话内间隔+交错）＋ 外层间隔重复（跨天到期召回）

内层｜刻意练习错词在其后第 1·3·6 个词复现（间隔+交错）；错误归因→微练
▼
自动评级（0–3 档）出错/速度/提示/首答 → Again·Hard·Good·Easy
▼
更新记忆卡稳定性 S↑、间隔指数拉长、重排到期日
⟳ 外层｜跨天：今日到期队列跨所有课包交错抽取，在「即将遗忘还能想起」时再提取（复习优先于新词）。

② SRS 卡片状态机 ＋ 零额外操作的自动评级

新词经会话内短步学习后「毕业」；复习失败回到重学；评级直接复用现有「出错 / ms每字母 / 提示 / 首答」信号与两套阈值。

③ 分阶段落地路线（P0 性价比最高）

每阶段都可独立上线、独立见效；P0 即可补上最关键的「跨天间隔」缺口。

P0

跨天间隔闭环

  • 新增 srs.js（SM-2＋学习步）与 review store，键 sp-srs-cards
  • 现有信号自动评级，存复习日志，迁移旧掌握度/慢词
  • 首页「今日复习」全局到期队列，复习优先于新词＋7天预测
  • 慢词连打 → 会话内 1/3/6 间隔交错复现
成本：低 ｜ 收益：最高（补上时间维度）
P1

刻意练习精准化

  • 持久化逐字母耗时/错误，定位卡顿点
  • 微练生成器：后缀 / bigram / 易混词 / 最小对立对
  • Leech 钉子词检测并换编码策略
  • 通道晋级阶梯（抄写→默写→听写→中译英）按阶段门控
成本：中 ｜ 收益：高（打准薄弱点）
P2

精加工与多语境

  • 构词法带义拆解、词源/关键词助记、配图
  • 词→句倒排索引：多语境复现＋挖空 cloze 卡
  • 跨课包按 lemma 合并为一张卡
  • 保持率仪表盘（R%/热力图/mature/leech）＋保持率每日目标
成本：中 ｜ 收益：中长期（深度理解）
P3

个性化与护城河

  • 用个人复习日志跑 FSRS 优化器替换 SM-2
  • 自适应阈值；遗忘边缘提醒 / PWA
  • Anki .apkg 导入导出；跨端同步
  • 跟读 / 发音评分作为新提取通道
成本：较高 ｜ 收益：差异化与留存
