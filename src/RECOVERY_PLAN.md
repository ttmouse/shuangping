## 应急恢复

### 关键文件备份
- `src/stores/writer.js` - 打字练习状态管理
- `src/utils/shuangpin.js` - 双拼核心逻辑
- `src/components/Keyboard.vue` - 键盘组件
- `src/data/schemes/` - 双拼方案定义

### 恢复流程
1. 检查关键文件完整性
2. 运行 `npm install` 确保依赖完整
3. 启动开发服务器 `npm run dev`
4. 验证基本功能
5. 逐步测试高级功能

### 回滚策略
如果新引入的问题无法快速解决：
1. 使用 git 回滚到上一个稳定提交
2. 重新应用关键修改
3. 避免有问题的功能
